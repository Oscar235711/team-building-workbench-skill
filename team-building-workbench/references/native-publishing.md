# 平台网页发布

用户可这样调用：

```text
使用团建工作台 Skill，人数20人、总预算6000元。
请使用当前平台自带的网页或应用发布功能，给我可转发给同事的工作台链接和管理员使用方式。
时间、玩法用预置词库，创建后在后台调整；参考活动未提供的内容先留空。
```

按当前会话实际能力选择入口，不预设所有账号都提供相同功能：

| 平台 | 提示词补充 |
| --- | --- |
| Claude | 优先使用当前可用的Artifacts或网页应用发布入口。 |
| Codex | 优先使用当前已连接的Sites或原生网页发布工具。 |
| 千问办公 | 优先使用当前办公空间的网页作品、应用或发布入口。 |
| WorkBuddy | 优先使用当前工作区的网站开发与发布、分享入口。 |
| DeepSeek | 使用当前会话实际提供的网页应用与发布能力。 |

沿用用户授权及平台访问设置。支持完整应用时使用平台数据库和服务端机密配置；仅支持前端时接入已有授权后端。多人方案、票数和留言必须共享同一服务端数据。

工具返回的实际工作台地址用于交付；聊天记录、源码链接和本地预览地址不称为已发布网站。若当前没有发布能力，给出可运行结果与实际需要的下一步。
