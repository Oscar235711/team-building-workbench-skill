# 宿主原生网页发布提示词

适用：用户希望把工作台发布在当前模型所在平台提供的网页上，而不是仅下载源码。只补问缺少的人数、总预算；原生发布是执行路径，不是新增业务必填项。

## 通用提示词

```text
使用团建工作台 Skill，为我们创建工作台：人数20人，总预算6000元。
请直接使用你所在平台自带的网页/应用创建和发布功能，发布到平台提供的页面，给我可以打开并转发给同事的工作台链接。
参考活动和费用我没提供就先留空；时间和玩法用预置词库，创建后允许管理员在工作台内修改。
保留方案提交与修改、投票统计、留言和管理员功能，各位同事访问同一份服务端数据。
直接交付链接和管理员使用方式，不附“未经测试”等清单，也不要求先跑完测试才能发布。
```

## 不同平台的表达

下列文字是让模型查找并使用**当前会话已有能力**的提示，不是对所有账号、版本或端口的功能承诺。

| 所在平台 | 可直接补充的提示词 |
| --- | --- |
| Claude | 请优先使用当前可用的 Artifacts 或网页应用创建、发布/分享入口，交付可以操作的工作台页面链接；需要多人共享时接入实际可用的共享后端。 |
| Codex | 请使用当前已连接的 Sites 或原生网页发布工具，创建独立工作台并发布；不要只交付本地 localhost 地址或代码。 |
| 千问办公 | 请在当前千问办公环境中查找并使用自带的网页作品、应用或发布/分享入口，直接生成并发布这个团建工作台，给我页面链接。 |
| WorkBuddy | 请优先使用当前工作区的网站开发与发布能力，完成后使用预览区的分享入口或对话中的“发布/上线”操作，返回独立工作台链接；共享数据使用平台可用的数据库能力。 |
| DeepSeek | 请使用当前 DeepSeek 会话实际提供的网页应用、作品预览与发布/分享功能，交付可交互工作台的页面链接；不要把聊天分享链接当成网站地址。 |

## 模型执行规则

1. 优先查看宿主已提供的工具、能力说明或可见入口。能直接创建与发布就继续，不让用户再选择一个云平台。
2. 原生工具支持完整应用时，保留模板的服务端权限和数据规则；可以适配宿主已有数据库/存储接口，不把SQLite强加给不支持它的平台。
3. 原生入口仅承载前端时，连接已有授权的共享后端，或选用当前可用的完整应用托管工具。不能用本机存储伪装成跨同事同步。
4. 发布范围遵守用户要求及平台当前设置。访问地址以工具返回或实际页面提供的链接为准，不把代码文件、聊天记录、短期本地预览冒充已发布工作台。
5. 无可用发布入口且无授权后端时，交付已有可运行结果，并用一句话说清实际缺少的能力。不附一长串未测试或未经验证事项。
6. 有时间和环境就做最小检查；没有条件跑测试也可继续发布，不把测试作为卡住交付的理由。没有执行的检查不声称执行过。

## 简洁交付示例

```text
工作台：[实际发布后的页面链接]
人数：20人；总预算：6000元。
时间和玩法已预置，可在管理后台调整。管理员入口/密钥领取位置：实际安全位置。
```

平台入口可能随版本变化，执行时以当前可用能力为准。Claude 官方介绍了 [Artifacts 分享](https://support.claude.com/en/articles/9547008-share-artifacts)；WorkBuddy 官方介绍了 [网站开发、数据库接入与发布](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/App-Publishing/Web-App)。其他平台不预写固定按钮路径，避免把某个版本的界面套用到所有用户。
